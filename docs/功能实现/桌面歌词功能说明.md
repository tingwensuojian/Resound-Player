# 桌面歌词功能说明

## 功能概述

在 macOS/Windows 桌面端播放音乐时，在桌面上显示一个独立的半透明歌词浮窗。支持滚动列表、单行、双行三种显示模式，可拖拽移动、调整大小，并支持锁定模式（鼠标穿透）。

## 架构总览

```
PlayerBar.vue (渲染进程)
  ├─ watch([lyricLines, currentTrack, isPlaying, currentTime]) → IPC desktop-lyric:update-data
  └─ watch(lyricLines) (独立，无条件兜底) → IPC desktop-lyric:update-data
       ↓
  electron/main.js (主进程)
  ├─ 启动: loadDesktopLyricConfig() → enabled && createDesktopLyricWin()
  ├─ desktop-lyric:update-data handler → 更新 desktopLyricData
  ├─ desktop-lyric:get-config → 设置页读取配置
  ├─ desktop-lyric:set-config → 设置页写入配置 → create / destroy / update window
  ├─ desktop-lyric:action ← 歌词窗口控制按钮 IPC (prev/next/togglePlay/toggleLock/close/fontSize±/switchMode/setColor/setTextColor/openSettings)
  └─ sendDesktopLyricToWin() → executeJavaScript('updateContent(...)')
       ↓
  createDesktopLyricWin()
  └─ BrowserWindow (无边框、透明、置顶、鼠标穿透支持)
       └─ data:text/html 内嵌 HTML
            ├─ body: 默认透明背景, .show-bg → 毛玻璃效果；背景仅一层，控制栏无独立背景层
            ├─ 顶栏: 左侧 Logo + 歌曲信息 + 播放控制(SkipBack/Play/SkipForward SVG) + 字体/颜色/模式/锁定/关闭按钮(无圆环背景)
            ├─ lyric-wrap: 歌词渲染区（.scroll-wrap 水平滚动支持）
            ├─ updateContent → renderLines → scrollToLine (scrollIntoView)
            ├─ updateProgress → requestAnimationFrame 行级 karaoke 渐变
            ├─ mouseenter → 显示背景 + 重置顶栏计时器（锁定且未启用始终显示时跳过）
            ├─ mousemove → 仅重置顶栏计时器（位置去重保护）
            ├─ mouseleave → 隐藏背景 + 立即隐藏顶栏 + 清除计时器
            ├─ pointerdown/pointermove/pointerup → JS 拖拽（`_state.isLocked` 时禁用）
            └─ updateLockState → 切换 body.locked class + 清除 show-bg（未启用始终显示时）
```

## 数据流

```
玩家播放歌曲 → PlayerBar 监听 playerStore 变化
         → window.appEnv.desktopLyric.updateData({
              lrcArray, currentTime, trackName, artist, isPlaying
            })
         ← 两路 watch 保证数据必达：
            1. 主 watch：`watch([lyricLines, currentTrack, isPlaying, currentTime])`
               带守卫 `if (!lines.length && track.id === lastId) return`，避免高频空数据
            2. 独立 watch：`watch(lyricLines)`，不带守卫，歌词加载完成后无条件发送
                                              ↓
                              desktop-lyric:update-data IPC
                                              ↓
                            desktopLyricData 更新
                            sendDesktopLyricToWin()
                                              ↓
                            executeJavaScript('updateContent(data)')
                                              ↓
        渲染进程 HTML:
          updateContent(data)
            ├─ 更新 _state.lyrc/highlightColor/textColor/fontSize/isLocked
            ├─ renderLines()
            │   ├─ 清空 #lyric-scroll 容器
            │   ├─ 空歌词时 s.innerHTML = ''; _state.curIdx = -1; 清空显示
            │   ├─ 遍历 lrc 数组创建 .lyric-line > .karaoke 元素
            │   │   ├─ idx === curIdx → .current 高亮样式（纯色 highlightColor）
            │   │   ├─ idx < curIdx  → .past 淡出样式（纯色 textColor）
            │   │   └─ idx > curIdx  → 纯色 textColor
            │   ├─ scrollToLine(idx) → scrollIntoView({ block: 'center' })
            │   └─ 启动 requestAnimationFrame 循环
            └─ startRaf() → updateProgress() 循环
                ├─ 计算当前时间在歌词中的位置 → 标记当前行
                ├─ 当前行：设置渐变 background-image（background-clip:text 内联）
                │   linear-gradient(highlight pct%, textColor pct%)
                ├─ 非当前行：清除 backgroundClip，恢复纯色渲染
                └─ scrollToLine(idx) 确保当前行居中

用户切换设置 → SettingsPage
            → window.appEnv.desktopLyric.getConfig() / setConfig()
                                         ↓
                                 desktop-lyric:get/set-config IPC
                                         ↓
                             主进程更新 config + 持久化
                             推送到窗口 + 通知所有 WebContents
```

## 三种显示模式

| 设置选项 | 内部 mode | 渲染方式 | 设计意图 |
|---------|-----------|---------|---------|
| **滚动列表** | `'scroll'` | 完整歌词列表，自动滚动到当前行居中 | 类似 Apple Music 的桌面歌词效果，适合跟唱 |
| **单行** | `'single'` | 仅显示当前行，居中大字号 | 简洁聚焦，适合桌面背景装饰 |
| **双行** | `'double'` | 显示当前行 + 下一行，纵向堆叠（当前行在上，下一行在下） | 兼顾当前进度与预览 |

当前实现在 `renderLines()` 中统一渲染全部歌词行，通过 CSS `scrollIntoView({ block: 'center' })` 控制居中滚动。

## 核心技术方案

### 窗口创建

- 独立 `BrowserWindow`，默认 800×200px（可调整）
- 无边框、透明背景（`transparent: true`）、无阴影
- `alwaysOnTop: true` 置顶，`skipTaskbar: true` 不在 Dock/任务栏显示
- `show: false` 创建，`ready-to-show` 时 `showInactive()` 展示
- `setVisibleOnAllWorkspaces(true)` 所有桌面空间可见
- `backgroundThrottling: false` 防止后台节流

```javascript
desktopLyricWin = new BrowserWindow({
  width: 800, height: 200,
  minWidth: 400, minHeight: 80,
  maxWidth: 1800, maxHeight: 600,
  frame: false, transparent: true, hasShadow: false,
  alwaysOnTop: true, skipTaskbar: true,
  resizable: true, movable: true,
  backgroundColor: '#00000000',
  show: false,
  webPreferences: {
    backgroundThrottling: false,
    contextIsolation: true,
    nodeIntegration: false,
    preload: path.join(__dirname, 'desktop-lyric-preload.js'),
  },
});
```

### HTML 渲染

使用 `data:text/html` 内嵌 HTML，避免额外的文件加载：

- 默认**透明背景**（`background: transparent`），光标悬停或启用"始终显示背景"时显示黑色毛玻璃背景（`body.show-bg` → `background: rgba(0,0,0,0.35)` + `backdrop-filter: blur(24px)`）
- `#lyric-scroll` 为滚动容器（`overflow-y: auto`，隐藏滚动条）
- 每条歌词为 `.lyric-line` + 内嵌 `.karaoke` span
- 控制栏位于窗口顶部，从左到右：Logo、歌曲信息、播放控制（SkipBack SVG / 播放暂停 / SkipForward SVG）、字体大小(A-/A+)、调色盘、显示模式切换、锁定、关闭按钮（按钮无圆环背景，hover 仅放大）

### 背景与顶栏显隐策略

背景和控制栏的显示逻辑完全解耦，互不影响：

| 事件 | 背景 | 顶栏 |
|-----|------|------|
| `mouseenter`（光标进入窗口） | ✅ 立即显示（解锁时） | ✅ 显示 + 重置 3s 自动隐藏计时器 |
| `mousemove`（光标在窗口内移动） | ❌ 不操作 | ✅ 显示 + 重置 3s 自动隐藏计时器（位置去重保护） |
| `mouseleave`（光标离开窗口） | ✅ 立即隐藏 | ✅ 立即隐藏 + 清除计时器 |

- 背景只由 `mouseenter` / `mouseleave` / `alwaysShowBg` 控制，不参与任何计时器；锁定时不响应 `mouseenter`，但 `alwaysShowBg` 启用后即使锁定也始终显示背景
- 顶栏由 `resetHideTimer()` 管理，`mousemove` 保持可见，3 秒无操作后自动隐藏
- `mousemove` 具有位置去重（`_lastMouseX/Y`），DOM 重建触发的伪事件被过滤
- 播放/暂停状态不影响背景和顶栏的显隐
- `updateContent()` 数据推送不触发任何显隐逻辑
- `d.isLocked` 守卫为 `!== undefined && !== _state.isLocked`，避免每次数据推送误触 `updateLockState` 重置计时器

页面加载 3 秒后顶栏自动隐藏（不显示背景），初始停留让用户看到歌曲信息：

### 颜色面板

桌面歌词窗口的颜色面板位于控制栏最左侧的调色板按钮中，分为两个独立区域：

- **已播放（高亮）** — 当前播放行的歌词颜色（纯色 hex，通过 `pickColor()` 设置）
- **未播放** — 未播放行和已播放行的文字颜色（纯色 hex，通过 `pickTextColor()` 设置）

两个区域均有 6 个预设色块 + 自定义取色器（`<input type="color">`），活跃状态互不干扰。

颜色值通过 IPC `setColor|` / `setTextColor|` 同步到主进程持久化，并广播 `config-changed` 通知设置页同步更新。

> 默认值和预设均使用 hex 格式（如 `#ffffff`），透明度由 CSS `opacity` 独立管理，确保与设置页 `<input type="color">` 兼容。

### 逐行居中 — `scrollIntoView({ block: 'center' })`

```
当前行切换 → scrollToLine(idx)
  → target = s.children[idx]
  → target.scrollIntoView({ block: 'center', behavior: 'smooth' })
  ↓
浏览器原生将目标元素滚动到滚动容器可视区域中央
无需手动计算 scrollTop / padding / clientHeight
```

- 解决了旧方案中 `s.clientHeight` 可能为 0 导致的居中失效
- 兼容所有边缘情况（内容不足、内容溢出、窗口 resize）
- 无需动态设置 `paddingTop` / `paddingBottom`

### 行级高亮（Karaoke 渐变）

桌面歌词使用行级 `linear-gradient` 实现当前行的 karaoke 揭示效果。

#### 渲染方式

桌面歌词**不**对逐字词（YRC `words`）做分支渲染。所有行统一创建 `.lyric-line > .karaoke` 结构，仅在当前播放行动态添加渐变。

非当前行使用纯 `color` 渲染，通过 CSS `opacity` / `transform` 区分层次：

| 行状态 | 颜色 | 透明度 | 缩放 |
|--------|------|--------|------|
| 当前行 (`.current`) | `highlightColor` | 1.0 | ×1.05 |
| 已播放 (`.past`) | `textColor` | 0.3 | ×0.88 |
| 未播放 | `textColor` | 0.5 | ×0.92 |

**当前行每帧更新渐变：**

```javascript
// updateProgress() 中，playMs 为当前播放毫秒
var n = nextLine.t * 1000;  // 下一行时间戳（ms）
var t = currentLine.t * 1000;  // 当前行时间戳（ms）
var p = Math.max(0, Math.min(1, (playMs - t) / (n - t)));  // 0→1
var pct = Math.round(p * 100);
k.style.backgroundImage =
  'linear-gradient(to right,' + highlightColor + ' 0%,' + highlightColor + ' ' + pct + '%,'
  + textColor + ' ' + pct + '%,' + textColor + ' 100%)';
k.style.backgroundClip = 'text';
k.style.webkitBackgroundClip = 'text';
k.style.webkitTextFillColor = 'transparent';
```

#### background-clip: text 的作用域

`background-clip: text` **不在 CSS 中全局设置**，仅在 `updateProgress` 更新渐变时通过内联样式动态添加。行切换时立即清除：

- **当前行更新渐变时** → 设置 `backgroundClip = 'text'`, `webkitTextFillColor = 'transparent'`
- **行切换时** → 清除 `backgroundClip`, 恢复纯 `color` 渲染
- **非当前行** → 没有 `background-clip`, 文本通过 `color` 属性直接渲染

这样避免了 Chromium 中 `background-clip: text` 无背景图时导致文字不可见的问题。

```lrcArray = lines.map((l) => ({ t: l.time, text: l.text }));
// words 字段不通过 IPC 传递（Vue reactive Proxy 无法被 structuredClone 序列化）
```

### 锁定模式与鼠标穿透

锁定后窗口进入**极简穿透模式**，仅显示歌词文字，不可拖拽、不可操作下方按钮：

- **鼠标穿透**：`setIgnoreMouseEvents(true, { forward: true })` 永久启用，所有点击穿透到窗口下方的应用
- **顶栏隐藏**：CSS `pointer-events: none` 使顶栏不可交互，仅 `.lock-btn` 保持 `pointer-events: auto`
- **锁定显示**：光标划过时无黑色背景（`show-bg` 不添加），仅锁按钮在右上角浮现
- **解锁方式**：光标移至窗口右上角（锁按钮区域）→ `startPoll` 检测到后临时取消穿透 → 点击锁按钮解锁
- **拖拽禁用**：锁定后 `pointerdown` 拖拽事件直接 return，`-webkit-app-region: drag` 已替换为 JS 控制
- **轮询机制**：每 100ms 检测鼠标位置，仅在锁按钮区域（右上 200×60px）临时取消穿透，其余区域保持穿透

#### 锁定状态对比

| 行为 | 解锁 | 锁定 |
|------|------|------|
| 拖拽窗口 | ✅ 任意位置拖拽 | ❌ 完全禁止 |
| 点击穿透 | ❌ 窗口捕获点击 | ✅ 穿透到下方应用 |
| 光标划过背景 | ✅ 显示毛玻璃 | ❌ 透明无背景（"始终显示背景"启用时除外） |
| 控制栏 | ✅ 完整显示 | ❌ 仅锁按钮可见 |
| 锁按钮 | 🔓 显示 | 🔒 光标移至右上角浮现 |

### 窗口位置与尺寸记忆

- **resize** → 防抖 500ms 写配置文件
- **move** → 防抖 500ms 写配置文件
- 重启后自动恢复位置和尺寸
- 配置文件：`~/Library/Application Support/Resound-Player/desktop-lyric-config.json`

### 时间同步

- 使用 `requestAnimationFrame` 驱动进度更新
- `_state.baseMs` 记录基准时间（毫秒），`_state.anchorTick` 记录 `performance.now()` 锚点
- `getPlayMs()` 返回当前播放毫秒：`baseMs + (performance.now() - anchorTick)`
- 暂停时固定为 `baseMs`，恢复时重置锚点
- 健康检查：每 1 秒检测播放时间是否超出歌词总时长 + 10s，超出则重置计时

### 错误隔离

- `window.onerror` 捕获未处理异常，通过 IPC `__error__` 前缀回传主进程
- `updateProgress` 内层 try-catch，个体错误不影响循环继续
- HTML 加载后 1s 健康检查，确认 `updateContent` 函数可用

## IPC 通信

| IPC 通道 | 方向 | 用途 |
|---------|------|------|
| `desktop-lyric:update-data` | 渲染→主进程 | 发送歌词数组、当前时间、播放状态 |
| `desktop-lyric:get-config` | 渲染→主进程 | 获取持久化配置（invoke） |
| `desktop-lyric:set-config` | 渲染→主进程 | 保存配置并更新窗口（invoke） |
| `desktop-lyric:action` | 桌面歌词窗口→主进程 | 控制按钮（播放/暂停/上一首/下一首/锁定切换/关闭/增大字号/减小字号/切换模式/设置颜色/打开设置）去除后移除了 openSettings |
| `desktop-lyric:config-changed` | 主进程→所有窗口 | 通知配置变更 |
| `tray:play-pause/next/prev` | 主进程→主窗口 | 控制播放（由桌面歌词 action 转发） |
| `desktop-lyric:move-window` | 渲染→主进程 | 增量移动窗口（delta dx/dy），带虚拟屏幕边界约束 |
| `desktop-lyric:get-bounds` | 渲染→主进程(invoke) | 获取窗口当前 bounds（位置+尺寸） |
| `desktop-lyric:get-virtual-screen-bounds` | 渲染→主进程(invoke) | 获取全部显示器的虚拟屏幕边界（含负坐标，支持多屏） |
| `desktop-lyric:resize` | 渲染→主进程 | 设置窗口宽高 |
| `desktop-lyric:set-height` | 渲染→主进程 | 仅设置窗口高度，保持宽度不变 |
| `desktop-lyric:toggle-fixed-size` | 渲染→主进程 | 拖拽时固定窗口尺寸（防 DPI 缩放漂移） |

### IPC 序列化限制

通过 `contextBridge` 的 IPC 使用 Electron 的 structured clone 算法（类似 `postMessage`）。**Vue 3 的 reactive Proxy 对象不能被序列化。**

因此 `desktop-lyric:update-data` 的数据中**不能包含** `LyricLine.words`（YRC 逐字词数组），否则会抛出 `An object could not be cloned` 错误，导致整个 IPC 调用失败。

```typescript
// ❌ 错误：words 是 Vue reactive Proxy，无法克隆
const lrcArray = lines.map((l) => ({ t: l.time, text: l.text, words: l.words }));

// ✅ 正确：仅传递纯对象，words 不经过 IPC
const lrcArray = lines.map((l) => ({ t: l.time, text: l.text }));
```

桌面歌词已统一为行级 karaoke，不依赖逐字词数据，因此不传递 `words` 字段。

### 翻译歌词与音译歌词

桌面歌词窗口支持显示翻译歌词（`translation`）和音译歌词（`romalrc`），数据来自 `LyricLine` 模型：

- `PlayerBar.vue` 将 `lyricLines` 中的 `translation` 和 `romalrc` 字段一并发送到桌面窗口（`lrcArray` 扩展为 `{t, text, translation?, romalrc?}`）
- 同步推送 `showTranslation` 和 `showRomalrc` 状态，与播放页歌词设置开关保持一致
- 桌面歌词窗口中，翻译和音译渲染在主歌词 `.karaoke` 下方的 `.sub-line` 标签中
- 翻译为普通字体，音译为斜体（`.sub-line.sub-roma`）
- 子行始终使用 `textColor` 渲染，字号 66%，透明度 0.55
- 子行不受 karaoke 渐变影响（仅主行有逐词揭示效果）

## 跨平台注意事项

- 桌面端可用（`platform.isDesktop`），非 macOS 特定
- 设置项通过 `platform.isDesktop` 控制可见性
- 所有 IPC 调用在 Web 端自动跳过（`window.appEnv?.desktopLyric` 检查）
- 遵循跨平台开发规范：业务代码不直接访问 `window.appEnv`

# 歌单详情页无限滚动实现说明

## 背景

歌单详情页（`PlaylistDetailPage.vue`）在加载雷达歌单等大歌单（如新歌雷达 5689 首）时，原有逻辑使用 while 循环一次性拉取全部歌曲，导致：

- 串行发出大量 API 请求（5689 ÷ 30 ≈ 190 次）
- 每次返回 30 首触发一次 Vue 响应式更新，造成页面卡顿
- 无法写入 localStorage（数据量太大）
- 补全数据不缓存，切页返回后重跑

## 解决方案

改为 **无限滚动（Infinite Scroll）** 模式：首次加载 30 首，用户滚动到底部时自动加载下 30 首，以此类推。列表渲染使用统一 **VirtualTrackList** 虚拟滚动组件。

## 架构

```
.playlist-detail-page          ← 唯一滚动容器（overflow: clip auto + overflow-anchor: none）
  DetailStickyHeroHeader       ← 吸顶头部（position: sticky）
  VirtualTrackList             ← 虚拟列表组件（parent 模式，监听页面级 scroll）
    └─ #default slot           每行内容（PlayPauseButton + 封面 + 歌名/歌手 + SongActions）
    └─ #sentinel slot          无限滚动哨兵（IntersectionObserver 监听）
```

### 滚动事件共存

| 组件 | 监听方式 | 作用 |
|---|---|---|
| `useDetailStickyState` | RAF + scroll | 写 `--sticky-progress`，驱动吸顶栏折叠 |
| `VirtualTrackList` | scroll + RAF | 写 `scrollTop`，计算可见行范围 |
| `setupInfiniteScroll` | IntersectionObserver | 监听哨兵，触发 `loadMoreSongs()` |

三者监听同一个 `.playlist-detail-page` 滚动容器，读写不同变量，互不干扰。

## 核心改动

### 文件：`src/components/PlaylistDetailPage.vue`

### 1. 移除 eager 补全循环

删除了 `fetchDetail()` 中的 `while (offset < max)` 循环（原 ~60 行），替换为：

```typescript
// 仅设置初始状态，不再立即加载全部
if (max > rawTracks.length) {
  infiniteState.value = {
    loading: false,
    hasMore: true,
    loaded: rawTracks.length,
    total: max,
  };
}
```

### 2. `infiniteState` 响应式状态

```typescript
const infiniteState = ref({ loading: false, hasMore: false, loaded: 0, total: 0 });
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `loading` | boolean | 是否正在加载下一页 |
| `hasMore` | boolean | 是否还有更多歌曲可加载 |
| `loaded` | number | 已加载的歌曲数 |
| `total` | number | 歌单总歌曲数 |

### 3. `loadMoreSongs()` 函数

```typescript
async function loadMoreSongs(id: number) {
  if (infiniteState.value.loading || !infiniteState.value.hasMore) return;
  const { data: chunkRes } = await getPlaylistTrackAll({ id, limit: 100, offset: st.loaded });
  // 去重后追加到 playlist.value.tracks
}
```

每次请求 100 首（优化后从 30 提升到 100），从当前 `infiniteState.loaded` 位置偏移。

### 4. `IntersectionObserver` 哨兵监听

```typescript
const sentinelRef = ref<HTMLElement | null>(null);
let scrollObserver: IntersectionObserver | null = null;

function setupInfiniteScroll() {
  scrollObserver?.disconnect();
  scrollObserver = null;
  requestAnimationFrame(() => {
    const sentinel = sentinelRef.value;
    if (!sentinel) return;
    const scrollRoot = props.embedded
      ? document.querySelector('.detail-panel')
      : document.querySelector('.playlist-detail-page');
    scrollObserver = new IntersectionObserver(
      (entries) => {
        if (entries[0]?.isIntersecting && infiniteState.value.hasMore && playlist.value?.id) {
          loadMoreSongs(Number(playlist.value.id));
        }
      },
      { root: scrollRoot, rootMargin: '400px' },
    );
    scrollObserver.observe(sentinel);
  });
}
```

哨兵元素通过 VirtualTrackList 的 `#sentinel` slot 嵌入，位于虚拟列表底部。

### 5. 虚拟滚动（VirtualTrackList 组件）

替换了原有的私有虚拟滚动实现（约 60 行代码）。删除内容包括：

- `ROW_HEIGHT`、`OVERSCAN` 常量
- `songListScrollTop`、`songListHeight` 状态
- `visibleRange`、`visibleTracks`、`totalListHeight` computed
- `cachedPageEl`、`onSongListScroll()`、`songListResizeObserver`、`pageScrollListener`
- `onMounted` 中的 ResizeObserver 和 scroll 事件绑定
- `onBeforeUnmount` 中的 ResizeObserver 和 scroll 清理
- 全部 `.song-list--virtual` CSS 规则

现复用统一组件：

```html
<VirtualTrackList
  ref="trackListRef"
  scroll-mode="parent"
  :scroll-host-selector="embedded ? '.detail-panel' : '.playlist-detail-page'"
  :items="filteredTracks"
  :row-height="68"
  :item-key="(t: any) => t?.id || t"
  container-class="song-list"
>
  <template #default="{ item: track, index: idx }">
    <div class="song-item" :class="{ 'song-item--playing': isCurrentTrack(track) }">
      <PlayPauseButton ... />
      <img class="song-cover" ... />
      <div class="song-meta">...</div>
      <SongActions ... />
    </div>
  </template>
  <template #sentinel>
    <div v-if="infiniteState.hasMore" ref="sentinelRef" class="infinite-sentinel">
      <span v-if="infiniteState.loading">加载中…</span>
      <span v-else>向下滑动加载更多</span>
    </div>
  </template>
</VirtualTrackList>
```

### 6. 哨兵自动挂载

```typescript
watch(
  () => infiniteState.value.hasMore,
  (hasMore) => {
    if (hasMore) {
      requestAnimationFrame(() => setupInfiniteScroll());
    }
  },
  { immediate: true },
);
```

### 7. 观察者清理

```typescript
onBeforeUnmount(() => {
  scrollObserver?.disconnect();
  scrollObserver = null;
});
```

VirtualTrackList 内部的 ResizeObserver 和 scroll 监听由其自身 `onBeforeUnmount` 清理。

### 8. 模块级会话缓存

```typescript
const sessionTrackCache = new Map<number, { tracks: any[]; total: number }>();
```

内存 Map，不写入 localStorage，同一会话内导航返回不重复加载。

## 工作流程

```
进入歌单详情页
  → getPlaylistDetail(id, 1000) 获取前 1000 首 + trackCount
  → 设置 infiniteState = { loading: false, hasMore: true, loaded: 1000, total: 5689 }
  → VirtualTrackList 渲染前 1000 首（虚拟化，DOM 仅 ~30-60 行）
  → watch 触发 setupInfiniteScroll()，挂载 IntersectionObserver

用户滚动到底部
  → 哨兵元素（#sentinel slot）进入视口
  → loadMoreSongs(id) 请求 offset=当前已加载数，limit=100
  → 去重后追加到 playlist.value.tracks
  → VirtualTrackList 自动检测 items 变化重新计算
  → 更新 infiniteState

Tab 切换（歌曲↔评论）
  → sentinelRef 重新挂载（v-if hasMore）
  → watch 触发 setupInfiniteScroll()
```

## 虚拟滚动详情

VirtualTrackList 组件（`src/components/VirtualTrackList.vue`）使用 `useVirtualScroll` composable 计算可见范围：

```
visibleRange.start = max(0, floor(scrollTop / rowHeight) - overscan)
visibleRange.end   = min(total, ceil((scrollTop + containerHeight) / rowHeight) + overscan)
totalHeight = items.length * rowHeight
```

父容器 scrollTop 通过 `containerRef.offsetTop` 转换为虚拟列表内偏移（每帧读取，适应吸顶栏折叠）。

## 性能优化对比

| 指标 | 原有 eager 模式 | 无限滚动 + VirtualTrackList |
|------|----------------|----------------------------|
| API 请求数 | ~190 次（一次性） | 按需（首次 1 次，后续每次滚动 1 次） |
| DOM 节点数 | 全部歌曲 DOM（大歌单数千个） | 30-60 个实时项 + spacer |
| 响应式更新次数 | ~190 次 | ~1 次/每次加载 |
| 首屏歌词加载 | 慢（等全部拉完） | 快（即时展示已有数据） |
| 页面卡顿 | 持续卡顿 | 无卡顿 |
| localStorage | 无法缓存（数据太大） | 不写 localStorage（内存 Map 缓存） |
| 代码复用 | 私有虚拟滚动实现 | 统一 VirtualTrackList 组件 |

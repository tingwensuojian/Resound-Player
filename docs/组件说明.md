# 组件说明

本文档说明当前项目中与统一详情页链路、媒体封面复用链路相关的核心组件职责。

## 1. `HomePanel.vue`

### 作用
首页内容面板，负责：

- 每日推荐卡片
- 私人雷达卡片
- 热门歌手
- 本周最热音乐
- 最新专辑推荐
- 新歌速递

### 与统一架构的关系

- 每日推荐卡片会把 `/recommend/songs` 适配成统一的 `PlaylistLike`
- 点击后进入统一播放/详情链路
- 播放逻辑已经切到公共播放工具

---

## 2. `PlaylistDetailPage.vue`

### 作用
统一的歌单详情页组件。

### 支持模式

#### 真实歌单模式
- 传入 `playlistId`
- 组件内部请求真实歌单接口

#### 注入模式
- 传入 `injectedPlaylist`
- 组件直接渲染注入数据
- 适合每日推荐、云盘等伪歌单

### 吸顶行为
- 由 `DetailStickyHeroHeader` 自动处理
- 连续滚动进度 `--sticky-progress` 驱动，无二值切换
- 自动检测最近可滚动父节点，无需传 `scrollHostSelector`

---

## 3. `UserPanel.vue`

### 作用
用户中心页面。

### 主要职责
- 展示用户信息
- 展示创建歌单、收藏歌单、收藏专辑
- 展示云盘
- 将云盘歌曲整理成统一伪歌单并注入 `PlaylistDetailPage`

### 与统一架构的关系

- 云盘不再单独画一套“特殊列表页”
- 统一走 `PlaylistDetailPage`
- 云盘数据通过 `cloudPseudoPlaylist` 注入

---

## 4. `UserSplitView.vue`

### 作用
用户中心的左右分栏布局组件。

### 结构
- 左侧：列表导航
- 右侧：详情展示区

### 与统一架构的关系

- 它只是布局容器，不负责数据业务
- 右侧详情区承载统一详情页
- 吸顶状态由 `DetailStickyHeroHeader` 自动检测右侧滚动容器（`.detail-panel`）并处理

---

## 5. `DetailStickyHeroHeader.vue`

### 作用
统一详情页吸顶头部组件，覆盖歌单/专辑/歌手/播客/用户详情页。

### 核心机制
- **连续进度驱动**：`--sticky-progress` 从 0（透明）到 1（纯色），RAF 单变量写入驱动背景色/毛玻璃连续渐变
- **高度显式过渡**：`height: 324px → 80px` + `overflow: hidden`，文档流跟随高度变化自然缩小，无需 clip-path
- **返回按钮过渡**：各详情页返回按钮已从 `v-if` 改为 CSS `back-fade` 过渡，消除布局跳动
- **语义与行为分离**：外层 `.playlist-detail-header-wrap` 是唯一语义 `header`，内层 `PageHeroHeader` 通过 `tag="div"` 渲染
- **内容不足保护**：列表高度不够时自动闭锁吸顶态，不触发跳动
- **ResizeObserver 测量内层高度**：测量的是 `.page-hero-header` 内层元素高度而非 wrap 自身，防止 `min-height` 自反馈膨胀循环

### 布局结构
- **基础态（展开）**：`PageHeroHeader` 两列网格 — 左列 `#media` 槽（封面），右列 `#content` 槽包含标题、元数据和操作按钮（自然排列在 `.hero-main-shell` 底部）
- **头部-内容区分隔线**：`::after` 伪元素在基础态显示渐变弱分割线，吸顶态自动隐藏
- **底部呼吸间距**：`padding-bottom: var(--space-2)` 在基础态提供呼吸感

### 吸顶态布局
- 封面缩小为 72px 圆角迷你方形（`border-radius: 6px`）+ `opacity: 0.95`
- 标题区 flex 拉伸占满，操作按钮在 flex 行右侧
- embedded 模式通过 `.detail-sticky-header--embedded` 微调 padding

### 封面效果
封面在滚动过程中连续缩小并上移：`.cover-motion-shell` 的 `scale` 从 `1` 渐进至 `0.8`、`translateY` 从 `0` 渐进至 `-16px`，由 `--sticky-progress` 实时驱动（非时间过渡）。吸顶态下 grid 缩小至 72px 列宽后，封面自然适配为圆角迷你方形。吸顶态封面保持 72px 自然比例显示，圆角从 18px 过渡到 6px，无缩放变形或模糊。

- 封面图
- 标题

## 11. `MvPlayPage.vue`

### 作用
MV 播放页，提供全功能 MV 播放体验。

### 功能
- 视频播放（HTML5 `<video>`，支持控制栏）
- MV 详情数据展示（名称、歌手、发布时间、点赞/评论/转发/收藏数）
- 评论区（复用 `CommentPanel`）
- 响应式布局（大屏：视频+侧栏，小屏：堆叠）
- **画中画（PiP）模式**：滚动查看评论区时，视频自动缩小浮动在窗口右下角继续播放

### 画中画实现
- 使用 Vue `<Teleport to="body">` 将浮动条渲染到 `document.body`
- 滚动检测基于 `.content` 的 `scroll` 事件 + `getBoundingClientRect()`
- 双 `<video>` 元素切换时同步 `currentTime` 保持播放连续性
- 详见 [docs/MV播放页画中画模式实现说明.md](./MV播放页画中画模式实现说明.md)

### 进入方式
- MV 列表页点击 MV 卡片
- 搜索结果中的 MV 条目
- 歌手页相关 MV

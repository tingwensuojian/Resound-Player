## 2. 迁移计划（3 阶段）

### 阶段 1：useApiData 组件迁移 → useApiQuery（2 个组件）

**目标：** `AlbumDetailPage.vue`, `ArtistDetailPage.vue`

```
useApiData → useApiQuery 映射

useApiData(cacheKey, fetcher, { ttl })
  → useApiQuery({ queryKey: [...], queryFn: fetcher, ttl })

返回值映射：
  data    → data       (useApiData: Ref<T|null>, useApiQuery: Ref<T|undefined>)
  loading → isPending  (useApiData: loaded=false+pending, useQuery: 首次加载中)
  error   → error      (useApiData: string, useQuery: Error | null)
  refresh → refetch    (同名)
  mutate  → mutate     (同名)
```

**迁移示例（AlbumDetailPage）：**

```ts
// 当前
const { data: albumData, loading, error } = useApiData(
  () => props.albumId ? `album:${props.albumId}` : '',
  () => getAlbumDetail(props.albumId).then(r => { ... }),
  { ttl: CACHE_TTL.ENTITY }
);

// 迁移后
const { data: albumData, isPending: loading, error } = useApiQuery({
  queryKey: ['album', props.albumId],
  queryFn: () => getAlbumDetail(props.albumId).then(r => { ... }),
  ttl: 'ENTITY',
  enabled: computed(() => Boolean(props.albumId)),
});
```

### 阶段 2：apiCache 直接操作组件 → useApiQuery（4 个组件 ✅ 已完成）

**目标：** `RankPanel`, `MvPanel`, `LanguageDetailPage`, `PlaylistPanel`（✅ 已完成）
**保留手动 apiCache：** `PlaylistDetailPage`, `HomePanel`（业务逻辑复杂，仅内联 CACHE_TTL 常量）

**迁移示例（RankPanel）：**

```ts
// 迁移前（手动 apiCache 操作）
const cached = apiCache.get('toplist:detail');
if (cached?.data) { list.value = cached.data; return; }
const { data } = await getToplistDetail();
list.value = (data?.list || []) as ToplistItem[];
apiCache.set('toplist:detail', list.value, CACHE_TTL.LIST_VOLATILE);

// 迁移后（useApiQuery）
const { data: toplistData, isFetching: loading, error: queryError } = useApiQuery({
  queryKey: ['toplist', 'detail'],
  queryFn: async () => {
    const { data } = await getToplistDetail();
    return (data?.list || []) as ToplistItem[];
  },
  ttl: 'LIST_VOLATILE',
});
const error = computed(() => queryError.value?.message ?? '');
watch(toplistData, (val) => { if (val) { list.value = val; hydrateCardTracks(); } }, { immediate: true });
```

## 4. 风险与注意事项

1. **返回值差异**：`useApiData` 的 `data` 是 `Ref<T | null>`，`useQuery` 是 `Ref<T | undefined>`。模板中的 `v-if="data"` 两者都兼容，但 `data ?? fallback` 行为不同（null vs undefined）
2. **loading 语义**：`useApiData` 的 `loading` 在后续刷新时仍为 true；`useQuery` 的 `isPending` 仅首次为 true，后续刷新看 `isFetching`。迁移时需区分 `isPending` vs `isFetching`
3. **错误类型**：`useApiData` 的 `error` 是 `string`，`useQuery` 是 `Error | null`。模板中 `error.message` 需改为 `error?.message ?? ''`
4. **缓存共存**：迁移期间两套缓存系统共存，`apiCache` 作为持久化后端被两者共享，不会出现双写冲突
5. **HomePanel 特殊处理**：该组件使用 `apiCache` 管理 10 个独立数据块，适合拆分为多个独立 `useApiQuery` 调用

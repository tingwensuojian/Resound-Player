# 歌曲列表渲染统一方案

## 当前状态

歌曲列表已通过 `VirtualTrackList` 组件实现统一虚拟滚动方案。

### 核心基础设施

| 文件 | 说明 |
|---|---|
| `src/composables/useVirtualScroll.ts` | 纯计算虚拟滚动引擎。输入 items/rowHeight/scrollTop/containerHeight ref，输出 visibleItems/totalHeight computed |
| `src/components/VirtualTrackList.vue` | 通用虚拟列表组件。Slot-based，每行内容和交互由调用方决定。支持两种滚动模式 |

### VirtualTrackList 组件

**Props**：

| Prop | 类型 | 默认 | 说明 |
|---|---|---|---|
| `items` | `any[]` | — | 数据源 |
| `rowHeight` | `number` | `68` | 行高(px) |
| `overscan` | `number` | `15` | 缓冲行数 |
| `scrollMode` | `'self' \| 'parent'` | `'self'` | 滚动模式 |
| `scrollHostSelector` | `string` | — | parent 模式必填，父滚动容器 CSS 选择器 |
| `itemKey` | `(item, index) => string \| number` | `(_,i) => i` | 行 key 生成函数 |
| `containerClass` | `string` | `''` | 附加到容器元素的 class（用于继承 `.song-list` 等公共样式） |

**Slots**：

| Slot | 参数 | 说明 |
|---|---|---|
| `#default="{ item, index }"` | `{ item, index }` | 行内容 |
| `#sentinel` | — | 底部哨兵区域（无限滚动用） |

**两种滚动模式**：

- **`self`**：组件自身 `overflow-y: auto`，适用于独立滚动面板（如 PlayQueuePanel）
- **`parent`**：监听外部滚动容器 scroll 事件，适用于详情页（与吸顶栏共享滚动容器）

每帧动态读取 `containerRef.offsetTop`，自动适应吸顶栏折叠导致的偏移变化。

**Expose 方法**：`refresh()` — 重置 scrollTop 为 0，适用于数据切换时重置滚动位置。

### 样式继承

通过 `container-class="song-list"` 继承 `detail-page.css` 中 `.song-list` 的公共样式（padding、border-radius、background）。各页面 slot 内 `.song-item` 也继承相同的基线网格布局。

## 使用方式

### 详情页（parent 模式）

```html
<VirtualTrackList
  scroll-mode="parent"
  :scroll-host-selector="embedded ? '.detail-panel' : '.playlist-detail-page'"
  :items="filteredTracks"
  :row-height="68"
  :item-key="(t: any) => t?.id || t"
  container-class="song-list"
>
  <template #default="{ item: track, index: idx }">
    <div class="song-item" :class="{ 'song-item--playing': isCurrentTrack(track) }">
      <PlayPauseButton ... />
      <img class="song-cover" ... />
      <div class="song-meta">...</div>
      <SongActions ... />
    </div>
  </template>
  <template #sentinel>
    <div v-if="hasMore" ref="sentinelRef" class="infinite-sentinel">...</div>
  </template>
</VirtualTrackList>
```

### 面板（self 模式）

```html
<VirtualTrackList
  scroll-mode="self"
  :items="queueItems"
  :row-height="54"
  :item-key="(t: any) => t.id"
  container-class="play-queue-list"
>
  <template #default="{ item: track, index: idx }">
    <div class="song-item" :class="{ 'song-item--playing': ... }">
      ...
    </div>
  </template>
</VirtualTrackList>
```

## 关键设计决策

### 1. VirtualSongList（本地音乐）为何不替换为 VirtualTrackList？

VirtualSongList 保留自实现虚拟滚动，原因：
- 需要选择模式（checkbox 列）
- 需要 sticky 表头 + 列排序能力
- 右键菜单（contextmenu 事件）
- 本地 track 数据格式（`LocalTrack`）与在线 API 的 Track 格式不同

但 **视觉已完全对齐** 详情页基线：68px 行高、52px 封面、3 列 grid 布局、自制 PlayPause（序号/播放/暂停/音浪）。

### 2. 为什么保留 SearchPage 的 v-for？

SearchPage 的滚动宿主是 `.content`（App.vue 主容器），与详情页的 `.playlist-detail-page` 不同。且搜索结果通常只有 20-50 首歌曲，虚拟化收益小。

### 3. 吸顶栏兼容性

`parent` 模式下，VirtualTrackList 每帧读取 `containerRef.offsetTop`，自动适应吸顶栏折叠导致的偏移变化。吸顶栏（`useDetailStickyState`）和 VirtualTrackList 各自监听同一个滚动容器的 scroll 事件，读写不同变量，互不冲突。

### 4. AnimatedAppear 入场动画

虚拟滚动会不断创建/销毁 DOM 节点（随用户滚动），与 AnimatedAppear 逐行动画不兼容。迁移后详情页歌曲列表不再有逐行入场动画。组件级别 AnimatedAppear（页面容器出现时）保留。

## Bug 修复记录

| Bug | 修复 |
|---|---|
| `.vtl-row` 设置 `overflow: hidden` 裁切 `song-item--playing` 的 box-shadow | 删除 `overflow: hidden` |
| PlayQueuePanel 的 `playerStore.playlist` reactive 数组响应性丢失 | 调用方包 `computed(() => playerStore.playlist)` |
| 搜索过滤后 `filteredTracks` 长度变化导致 scrollTop 越界 | VirtualTrackList 内部 `watch(items.length)` 截断 |
| 替换 VirtualTrackList 后 `.song-list` 公共样式（背景/圆角）丢失 | `containerClass` prop 透传 |
